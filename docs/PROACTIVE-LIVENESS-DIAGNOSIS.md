# SOOYA 主动消息"没有活人感"诊断与改造

> 2026-09-23。依据：kaze1 线上 release 20260909153142（`core/proactive.ts` 与 `origin/main` 一致）+ 线上库只读查询。改动分支 `feat/proactive-private-message`，基于 `origin/main` 8f7dd57。

## 1. 现状证据

- 配置：`lifePolicy = { quietGapMinutes: 180, maxReachOutsPerDay: 10, proactiveMode: "image", silent 0–9 }`，`QQ_PROACTIVE_ENABLED=true`。
- 最近 45 条主动消息中 44 条是"生活动态"原文转发到 QQ，写法是日记体（"昨天下午把唱机搬到了窗边……"）。
- 重复：“给房间换个布置”三次、“多肉冒新芽”六次以上，文字几乎相同。
- 节奏机械：09-13 发于 09:06 / 12:11 / 15:16，间隔精确 3h05m；09-11→09-16 用户几乎没说话，她照样每三四小时发一条自己的日常。
- 回复率（`interaction_outcomes`）：life 带图 26 条只回 1 条，纯文字 8 条回 2 条。

## 2. 根因

1. Prompt 把主动消息定义成“发到动态、这里不是私人聊天窗口”，并禁止“发给你看看”这类私聊语气——但她根本没有朋友圈，所有消息只发给用户一个人。
2. 生成时看不到对方：没有最近对话、对方多久没来、上一条有没有回、最近发过什么。
3. 节奏只有一个固定 180 分钟门槛，不看是否被回复，无退避、无随机。
4. `proactiveMode: image` 下每条都被要求配图，形态单一、像发文案。
5. 反馈统计本身在工作，但权重只影响候选排序，不影响“要不要发 / 多久发一次”。

## 3. 已完成的改动（未部署）

`packages/server/src/core/proactive.ts`：

- **主动消息 = 发给对方一个人的私聊**。Life 小事只是“可以提也可以不提”的开口由头；prompt 带入最近 16 条聊天、对方上次说话距今多久、上一条是否未回、最近 6 条主动消息（禁止重复）。要求短、口语、直接对着对方说；禁止日记体/旁白开头/文案感。
- **节奏**：间隔 = `quietGapMinutes × 稳定抖动(1.0–1.6) × (上一条未回 ? 2 : 1)`；连续 2 条未回 → `awaiting_reply`，Life 分享停发直到用户再出现（承诺/日程类关心不受此限）。
- **配图可选**：image 模式下由她判断“是否真的想拍给对方看”，多数时候不配；不配记为 `no_photo_chosen`。
- Moment 行保留为内部记录（Web 生活面板仍可看），数据结构不变。

测试：新增 3 条（私聊 prompt 上下文、两条未回停发、未回时间隔翻倍），更新 1 条时间文案断言。全量 155 文件 / 1308 用例通过，typecheck、架构边界检查通过。
