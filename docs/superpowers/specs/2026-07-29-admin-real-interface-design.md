# SOOYA 管理面板真实接口设计

## 目标

先发布一个不含占位数据和无后端按钮的正式管理面板，再补齐缺失接口并增量扩展。

## 第一阶段：只接已有接口

- 概览：系统、数据库、存储、能力和备份摘要。
- 助手配置：读取和保存单一 persona。
- 模型配置：编辑现有 `chat`、`vision`、`summary`、`embedding`、`image`、`tts`、`stt` 配置；不引入模型库概念。
- 内容管理：记忆、媒体、表情包、清空聊天。
- 运维与备份：错误、任务、备份创建、校验、恢复、删除。

正式页面不展示以下尚无接口的内容：头像文件上传、生图参考图、多模型资料库、模型自动发现、真实连接测试、历史趋势、实时日志、服务重启、配置重载和缓存清理。

## 第二阶段：补缺失接口

按独立资源实现：

1. 管理媒体上传与头像保存。
2. 生图参考图 CRUD。
3. 模型资料库、能力分配、模型发现与连接测试。
4. 统计指标、请求历史和日志读取。
5. 安全的服务运维操作。

所有写操作继续使用 `X-Admin-Token`，密钥读取必须脱敏，危险操作要求显式确认。

## 验证

- Web 类型检查、构建和 Playwright 管理面板测试。
- Server 单元测试、类型检查和现有安全/可靠性测试。
- 部署后通过 localhost 和公网健康检查验证。
