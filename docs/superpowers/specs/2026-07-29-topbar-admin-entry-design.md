# 顶栏管理入口样式

## 目标

将聊天页右上角的管理入口改为极简线框样式，减少视觉重量，同时保留清晰的可点击性和现有 `/admin` 跳转行为。

## 设计

- 位置不变：在聊天头部的最右侧；窄屏时距屏幕右侧 14px。
- 尺寸为 30px 圆形，白色背景、1px 蓝灰细描边。
- 齿轮使用 16px 内联 SVG（24×24 画布、以中心点对齐），而非系统 Emoji；默认无渐变、无投影。
- 悬浮或键盘聚焦时使用很浅的蓝灰背景，按下时轻微缩放。
- 不调整登录、管理面板、链接地址或令牌逻辑。

## 验证

- E2E 检查入口仍位于顶栏右侧且链接到 `/admin`。
- 新增视觉契约：入口尺寸为 30px，圆形，默认无盒阴影。
- 运行生产构建，并用手机宽度从公网检查实际位置。
