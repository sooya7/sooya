# SOOYA H1–H10 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the confirmed H1–H10 security, durability, reconnect, PWA, protected-media, and SQLite-recovery risks without expanding the SOOYA 1–9 product scope.

**Architecture:** Deliver four independently testable risk slices: security/error containment, durable chat state, PWA/protected-media lifecycle, and copy-based SQLite recovery. Durable database state and replay events share transactions at stable boundaries; browser recovery uses explicit cursors and reconciliation; protected media always uses header-authenticated fetches; database salvage never mutates the only live WAL set.

**Tech Stack:** TypeScript, Fastify, better-sqlite3, React, Vitest, Vite, Service Worker/Cache API, Playwright, Docker.

---

## Scope and finding corrections

- H1 is confirmed: message rows and their durable replay events are currently separate commits.
- H2 is partially confirmed: concurrent withdrawal can race and return 500. The report's claim that it can delete streaming assistant parts is false because user and assistant messages have different IDs. Do not introduce a global reply lock for this.
- H3 and H4 are confirmed: reflected credentialed CORS and upstream error text exposure require containment.
- H5 is confirmed as a recovery risk, but deleting or moving a live WAL/SHM before a copy-based probe is unsafe and is explicitly forbidden.
- H6, H7, H8, and H10 are confirmed.
- H9 is partially confirmed: gallery loading already creates authenticated Blob URLs. Raw download/viewer fallbacks and avatar consumers still bypass the unified loader and must be fixed.
- M1–M18, L1–L15, simulation scheduling, offline world catch-up, and daily plans are outside this plan.

```ts
persist(type: StreamEventType, payload: Record<string, unknown> = {}): StreamEvent {

fanout(event: StreamEvent): void {
  this.emitter.emit('event', event);
```
