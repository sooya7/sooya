# 行为决策模型

在「模型配置 → 行为决策」配置并启用。默认关闭，升级不会自动向新服务发送对话。

## 支持的服务

| 服务 | 模型 | 接口基础地址 |
| --- | --- | --- |
| 阿里百炼（北京） | `decision-model-preview` | `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| 阿里百炼（新加坡） | `decision-model-preview` | `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` |
| TypeSafe Jev | `jev-latest` | `https://api.typesafe.ai/v1` |
| 自定义 System One | 按供应方设置 | HTTPS 基础地址或完整 `/systemone` 地址 |

两家使用相同的 System One 请求结构；不意味着底层模型或效果相同。目前一次使用一个提供方，切换提供方时需重新填写对应密钥，没有隐式跨提供方回退。密钥通过原有配置存储保存，管理 API 只返回配置状态。

协议依据（2026-09-26 核对）：[阿里官方 API](https://help.aliyun.com/en/model-studio/decision-model-api)、[TypeSafe 官方 API 示例](https://docs.typesafe.ai/introduction/quickstart)。

## 行为

每个回复批次在主模型生成前，发送本轮文字（最多 12000 字符）和最近有限文字上下文（最多 6000 字符），一次询问四个独立 `noul` 问题：记忆、图片、视频、语音。允许文字与媒体共同使用。模型返回的是肯定概率，不是正确率保证。

- 记忆概率低于 0.55：不为本次回复创建自动记忆任务。
- 0.55 至 0.85：进入现有记忆提取或 Ombre 提交流程复核。
- 0.85 及以上：进入同一记忆流程。决策模型不直接把原文存成事实，提取、去重、存储权限等仍由原有系统负责。
- 明确「记住」优先进入记忆流程，明确「不要记住」跳过。功能关闭时维持原流程。
- 媒体概率达到 0.85 时提示主模型准备对应媒体意图；低于或等于 0.15 时屏蔽本轮自主媒体意图；中间区间由主模型判断。语音肯定判断还可补充语音意图。
- 用户明确要求优先于模型低分；明确禁止图片、视频或语音时仍受用户指令约束。媒体能力、频率与额度限制继续生效。图片与视频的具体内容由主模型和现有媒体导演生成。

阈值可在后台调整。默认整次决策请求最多 2000 毫秒，无重试；超时、断网、HTTP 错误、缺少字段或概率无效时回退原流程。回复被新消息取消时，决策请求跟着取消。结果状态、概率和执行选择写入最终回复的 `meta.behaviorDecision`，不记录请求正文或密钥。

「测试已保存配置」仅请求判断并展示概率，不创建记忆、图片、视频或语音。测试结果不代表长期效果，启用前应使用自己的典型中文消息检查。

## 验证边界与回滚

单元测试覆盖三种官方地址、请求格式、阈值、显式记忆指令、坏响应、总超时和取消；回复集成测试覆盖媒体抑制、明确生图请求、记忆任务入队、故障回退及管理接口鉴权/脱敏。浏览器检查覆盖提供方切换、配置保存与重载、未配置密钥提示及窄屏布局。

这些测试使用隔离数据和模拟模型，不证明真实供应方可用性。真实密钥与 Workspace ID 必须由部署环境配置并在后台执行连通性测试。

关闭「启用行为决策」立即恢复原有主模型和记忆调度方式，无数据库迁移。
